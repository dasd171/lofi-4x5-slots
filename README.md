# Lofi 4x5 Slots

A 4x5 slot machine mini-game featuring Lofi the Yeti, built for **CLAY Hackathon III** (Lofi Foundation) — mini-game track.

## Play

Open `index.html` in any modern browser. No build step, no server, no real money — play money only.

- 5 reels x 4 rows, cascading-style spin with per-reel stops
- Lofi the Yeti is the WILD; Cassette Scatter triggers free spins
- Aurora Jackpot, full paytable, spin history and stats
- One-click entry poster export (1200x630 PNG)

## Theme

Arctic meme legend meets crypto chill. Symbols: Yeti, Bitcoin, Ethereum, Cassette, Headphones, Hot Cocoa, Snow Pine, Crescent Moon, Snowflake, Ice Fish.

## Hackathon

- Event: CLAY Hackathon III — https://hackathon.lofitheyeti.com
- Track: Build a mini-game featuring Lofi
- Network: Sui ecosystem (game is a standalone web build; no on-chain deployment required)
